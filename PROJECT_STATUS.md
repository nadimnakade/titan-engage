# Titan Engage Prototype V1 Status

## Implemented

- Responsive application shell, navigation, search, entity switcher, notifications and profile controls
- Dashboard with metrics, revenue visualization, activity, invoices and receivables
- Searchable and filterable quotation and invoice lists
- Shared quotation/invoice builder with customer and product selection
- Dynamic line items, integer minor-unit calculations, discounts and tax
- Live professional document preview and print/PDF workflow
- LocalStorage persistence, seeded data, toast feedback and demo reset
- Responsive mobile editor/preview tabs
- Full customer, product/service, payment and tax profile CRUD workflows with local persistence
- Reports centre with selectable reports, filters, charts, tables and CSV exports
- Branding editor with live invoice preview, colour controls and persistent template selection
- Settings centre with business profile, users and configurable organisation options
- Requirement-driven quotation workspace with independent lifecycle, archive/trash, conversion and email states
- Advanced quotation views, combined filters, bulk actions, duplicate, PDF and quote-to-invoice prototype flows
- Quotation detail workspace with items, notes, email history and immutable-style activity timeline
- Universal custom-field builder and reusable product-template configuration with local persistence
- Quotation-specific VAT display, PDF/branding and email-template settings

## Next production phase

After stakeholder approval, connect the prototype services to the planned .NET API and PostgreSQL database, then add authentication and tenant isolation.
