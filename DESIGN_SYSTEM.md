# Titan Engage Design System

Titan Engage uses a restrained enterprise SaaS language: midnight navy navigation, Titan Blue actions, a bright neutral workspace, compact data density, 9–14px radii, and subtle elevation.

## Core tokens

- Midnight Navy `#101827`
- Titan Blue `#2563EB`
- Electric Blue `#38BDF8`
- Slate Grey `#64748B`
- Success `#16A34A`, Warning `#F59E0B`, Error `#DC2626`
- Typography: Plus Jakarta Sans with Inter and system fallbacks

Primary actions are solid blue; secondary actions are white with a light border. Document previews deliberately use a flatter, print-oriented visual language.

## Commercial UI direction

The product uses a data-dense enterprise dashboard pattern with balanced modern variance and restrained motion. Navigation and system actions use one consistent outline SVG family. Controls maintain 44px interaction targets, visible keyboard focus, WCAG-oriented contrast, adaptive gutters, and internal table scrolling on small screens. Titan Blue and Electric Blue remain the distinguishing accents; gradients are reserved for branded navigation states rather than general decoration.
